# AI 垂类账号视觉品牌母版配置（Brand Visual）

> 本文件供 `xhs-visual-studio` 在视觉规划阶段自动加载，确保多篇小红书笔记形成稳定的个人 IP 视觉辨识度。

## 1. 全局画布与出图引擎硬约束

- **统一画幅**：`3:4` 竖版（`1080x1440px, strict 3:4 vertical portrait canvas`）
- **默认出图后端**：`google`（通过 `baoyu-image-gen --provider google` 调用 Google Gemini 多模态生图）
- **默认模型**：`gemini-3-pro-image`（高速预览或降本可切换 `gemini-3.1-flash-image`）
- **默认画质**：`2k`（`imageSize: 2K`）
- **批量并发数**：`4`
- **一致性铁律**：
  1. 每套图文必须先单独生成第 1 张封面（`01-cover.png`），经人工确认样图后再生成后续页面。
  2. 生成第 2..N 页时必须把 `01-cover.png` 作为 `--ref` 参考图传入（首图锚定链），锁定色系、字体质感与卡片圆角。
  3. 严禁使用代码/位图工具在已生成图片上二次贴字涂改；若文字出错，修改对应 Prompt 文件后仅重生成该页。

## 2. AI 垂类默认双轨路由策略

| 内容类型 | 自动命中的视觉轨道 | 默认风格与布局组合 |
| :--- | :--- | :--- |
| 工具清单、教程步骤、Prompt 模板、长文拆解、多图干货 | **轨道 A：快轨（干货卡片）** | 主推 `notion` + `dense`/`list`，或 `sketch-notes` + `flow`（配色默认或 `macaron`） |
| AI 深度观点、架构图拆解、行业趋势、爆款高点击封面、个人 IP 宣言 | **轨道 B：精轨（高定导演）** | 主推 **深色科技杂志风** / **黑白灰 + 荧光绿冲击风** / **架构图系统拆解风** |

## 3. AI 垂类品牌视觉令牌（供精轨母版锁定前缀复用）

- **主视觉基调**：深炭黑 / 极简白纸双系列（观点类用深炭黑 `#0E1117`，干货收藏类用暖白/极浅灰 `#F7F8FA`）
- **核心强调色**：荧光薄荷绿 `#00E599`（或电光蓝 `#2563EB`），单页严格只选 1 个强调色用于核心数字、关键词或箭头连线
- **安全边距**：左右 `72px`、上下 `80px`，页码统一置于右下角低权重小号无衬线体
- **绝对禁止项**：廉价蓝紫赛博渐变、密集发光杂乱线条、像普通 PPT 截图的居中 bullet 列表、文字过小导致手机端模糊不可读

## 4. 品牌头像与水印偏好
