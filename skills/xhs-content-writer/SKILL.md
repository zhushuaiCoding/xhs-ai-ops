# 内容创作与爆款复刻（模块 3）

> 路径约定：下文中 `<XHS_OPS_ROOT>` 指 `xhs-ai-ops` 项目根目录（即本技能 `SKILL.md` 所在目录的上两级，如 `./xhs-ai-ops`）。


本技能承接模块 2 的 `01_research.md`（或用户直接输入的草稿/爆款链接），产出高网感、去“AI 报告腔”、严格符合小红书字数与合规红线的完整文案和配图分页大纲，供模块 4（`xhs-visual-studio`）和模块 5（`xhs-publish-engage`）消费。

- **必读人设与历史经验**：
  - `<XHS_OPS_ROOT>/config/persona.md`
  - `<XHS_OPS_ROOT>/knowledge-base/README.md`

## 工作模式一：原创笔记撰写

基于 `01_research.md` 中用户拍板的选题，严格按照 `config/persona.md` 的 AI 垂类实战派口吻输出标准小红书五元组：

1. **候选标题（3–5 个）**：
   - **硬约束**：每个标题严格 **`≤ 20` 个中文字/字符**（超出小红书发布端会被截断或拒发）。
   - 必须覆盖不同策略：至少包含 1 个反差/避坑型、1 个结果/提效型、1 个清单/干货收藏型，并标出最推荐的 1 个。
2. **正文文案**：
   - **硬约束**：严格 **`≤ 1000` 字**（推荐 300–650 字，手机端阅读体验最佳）。
   - **硬约束**：**正文末尾绝不写 `#标签`**——所有话题统一放进独立 `tags` 数组（因为 `xiaohongshu-mcp` 的 `publish_content` 会自动通过 `tags` 参数写入官方话题实体）。
   - 结构节奏：开头 1–2 句强钩子 → 三段式干货主体（痛点/方案/实测对比） → 1 句自然收尾与低门槛互动提问。
   - 排版风格：短句、多空行、克制使用 3–6 个 Emoji，禁用“首先/其次/综上所述”等报告体。
3. **独立话题标签数组（`tags`，5–8 个）**：
   - 组合策略：2 个大流量行业词（如 `AI工具`、`效率神器`） + 3 个精准垂直词（如 `AIAgent`、`开源项目`、`工作流自动化`） + 1–2 个场景词。
4. **评论区运营配置**：
   - **可置顶评论（1 条）**：补充干货清单、避坑提醒或抛出轻量站队投票，拉高评论区停留。
   - **互动追问点（2 条）**：预留读者可能追问的方向，方便后续模块 5 接梗。
5. **配图分页内容大纲（4–8 页）**：
   - 明确封面主副文案 + 每页仅承载 1 个核心要点 + 结尾页 CTA，直接交给模块 4（`xhs-visual-studio`）进入视觉策划。

## 工作模式二：爆款笔记结构复刻（Viral Copy）

当用户输入一条小红书爆款链接或笔记 ID 时：

1. **结构化采集原帖（统一走 `xiaohongshu-mcp`）**：
   - 若用户只给了链接或关键词，先通过 `search_feeds` 定位获取 `feed_id` + `xsec_token`，再调用 `get_feed_detail`（必要时 `load_all_comments=true`）获取完整标题、正文、配图 URL、点赞收藏比及高赞评论。
2. **输出精简 `Source Template` 拆解**：
   - 标题句式骨架（情绪词 + 具体对象 + 收益/反差）
   - 封面信息层级与字数密度
   - 正文节奏与情绪曲线
   - 评论区触发词与低门槛互动机制
3. **结构级改写（默认 `style-only`）**：
   - **默认模式 `style-only`**：保留同赛道议题与已被验证的互动结构，但**彻底重写全部文案、替换真实案例细节、重设计封面与配图元素**。
   - 仅当用户显式指定时才切换 `medium` 或 `tight`。
   - **绝对禁止**：逐句照抄原帖文本、直接下载并二次使用原帖图片、搬运原作者专属隐私/品牌标识。

## 发布前文案合规强自检（写盘前必查）

在生成 `02_copy_draft.md` 末尾附带以下核查表，任何一项不通过必须先修正：

- [ ] 推荐主标题长度 `≤ 20` 字（精确计数核对）
- [ ] 正文总字数 `≤ 1000` 字，且不含 `#话题` 文本
- [ ] `tags` 独立数组为 5–8 个精准标签
- [ ] 无违禁极限词（“必爆”“最牛”“稳赚”“100%有效”等）
- [ ] 无微信号、公众号、二维码等站外导流信息
- [ ] 无虚构的实测数据或未经授权的“明天发资料”隐性承诺
- [ ] 语感符合 `config/persona.md`，无明显 AI 模板腔
